## ✅ 已由官方资料确认的结论（无需再测）

### 第 2 项：智能机器人能否进客户群（含微信用户的外部群）？——【不能】

这是**决定性结论**：企业微信官方智能机器人**不支持外部群**。

| 证据 | 来源 |
|---|---|
| 「内部群聊使用：仅支持添加至企业内部群，机器人可识别群内 @它 的消息并回复；**互联群、上下游群、外部群暂不支持添加**」 | 企业微信帮助中心 [如何使用智能机器人](https://open.work.weixin.qq.com/help2/pc/21663) |
| 「外部群 = 包含企业外部成员（企业微信用户或**微信用户**）的群聊」 | 企业微信 [外部群介绍](https://work.weixin.qq.com/wework_admin/customer/externalGroupIntro) |
| 「目前包含外部联系人的群聊不支持添加机器人」 | 企微群机器人官方限制（Gitee 等接入文档均有引用） |

**含义**：你们客服面对的是**微信客户**，客服群本质就是「外部群」。官方智能机器人 API
（长连接、@回调、大模型那套）**只能在纯内部员工群用，客户群用不了**。
客户群唯一的官方自动回复路径是「客户联系 → 效率工具 → 自动回复」（@小助理关键词回复，
零代码、不能接自定义程序）。

## 📋 需要用现成企微账号实测/确认的项

### 第 1 项：现成账号是否为管理员（约 5 分钟）

1. 电脑登录企业微信管理后台：https://work.weixin.qq.com/
2. 能正常登录并看到「我的企业」「应用管理」「客户联系」等菜单 → 是管理员（或有分级管理员权限）
3. 进入「应用管理」，底部能看到「智能机器人」→ 有创建权限
4. 进入「客户联系」→ 能看到「效率工具 → 自动回复」→ 有客户群配置权限

记录：☐ 是超级管理员 ☐ 是分级管理员（权限范围：______）☐ 普通成员（需找管理员）

### 第 3 项：客户群自动回复的实际能力边界（约 20 分钟）

1. 管理后台「客户联系 → 效率工具 → 自动回复」，新建规则：
   - 关键词：`测试快递`（匹配方式选「包含」）
   - 回复内容：`✅ 自动回复测试成功，请提供订单号`
2. 建一个**客户群**：企微里发起群聊，拉 1 个同事的企业微信 + 用一个**微信小号**扫码/邀请进群（微信用户即外部客户）
3. 用微信小号在群里发：
   - `@小助理 测试快递` → 预期：自动回复（验证客户群+微信用户可用）
   - `测试快递`（**不 @**）→ 记录：是否也自动回复？（官方文档要求 @小助理/@服务人员）
   - 连续加关键词，测**规则条数/话术条数上限**（加到 50 条看是否受限）
4. 记录：回复消息里**能否 @ 某个成员**（话术编辑器里插入 @ 人 → 此项即第 3 项的 @ 指定人员能力）

记录表格：
| 测试点 | 结果 |
|---|---|
| 微信用户在客户群 @小助理 触发回复 | ☐ 成功 ☐ 失败 |
| 不 @ 直接发关键词是否触发 | ☐ 触发 ☐ 不触发 |
| 回复内容能否 @ 指定成员 | ☐ 能 ☐ 不能 |
| 关键词规则条数上限 | 约 ____ 条 |
| 回复支持的内容类型 | ☐ 文字 ☐ 图片 ☐ 网页 ☐ 小程序 |

### 第 4 项：客户群迁移可行性（约 20 分钟，可与第 3 项合并）

1. 现有微信客服群里，客户用的是个人微信；企微客户群支持微信用户加入，但**群必须在企微侧新建**
2. 在客户群设置里看「加入群聊」二维码/「联系我」链接的生成路径：
   管理后台「客户联系 → 加客户 → 加入群聊」，可生成二维码/按钮，客户扫码即进企微客户群
3. 评估：让现有微信群客户扫码进新群的话术和转化率（这是组织动作，非技术问题）
4. 记录客户群人数上限、客户进群是否需要审核等限制

### 第 5 项：会话存档报价与开通（约 15 分钟，只看不开通）

1. 管理后台「管理工具 → 会话内容存档」（看不到该入口 = 企业未开通/无权限，需管理员）
2. 查看开通流程：需企业认证、下载公钥、配置可信 IP、签署告知同意
3. 价格核实：
   - 腾讯官方**接口免费**，但需要企业有开发能力接入；
   - 第三方实施（芝麻微客/企微云等 SCRM）市场价约 **200–900 元/人/年**（按开通存档的员工数计费），
     在「管理工具」或联系企微服务商获取本企业的准确报价
4. 注意：会话存档是**审计留痕**能力，不能用来驱动自动回复

记录：☐ 能看到存档入口 ☐ 报价：______ ☐ 需告知/同意的流程说明：______

### 第 6 项：内部群智能机器人开发验证（可选，约 40 分钟）

> 仅当「内部群也需要机器人」（比如内部仓库、发货协同群）才需要做。
> 客户群已确认用不了智能机器人，本项只验证内部场景。

提供的验证脚本（Node.js，复用钉钉机器人的长连接模式）：

1. 管理后台「应用管理 → 智能机器人 → 创建机器人」，记录：
   - 机器人名称、BotID（aibotid）
   - 选择「长连接模式」（无需公网服务器）
2. 创建机器人后获取企业凭证：`corpid`（我的企业 → 企业ID）、机器人 `secret`
3. 在**内部群**里添加该机器人（群设置 → 群机器人 → 添加）
4. 运行验证脚本：

```powershell
# 需要 Node.js 18+
cd D:\DeepSeekHarness\wechat-kefu\docs\wecom-poc
npm install
# 把 corpid / 机器人secret 填入 .env
$env:WECOM_CORPID="你的企业ID"
$env:WECOM_BOT_SECRET="机器人secret"
node index.js
```

5. 在内部群 @机器人 发「测试」→ 脚本应打印收到的回调消息并自动回复
6. 在回复内容里测试 @ 群成员（验证第 3 项在内部群/API 模式下的 @ 能力）
