# 客服微信助手 · 专用主机部署 SOP

## 架构

```
专用 Windows 主机（只负责收发微信）
├── PC 微信 4.1.8.107（登录专用工作号）
├── 客服微信助手 bot（常驻，自动收发/转发，崩溃自动重启）
└── Web 管理面板（绑定局域网，带登录密码）
      ↑
   同办公室客服浏览器访问 http://主机IP:43991，输密码后远程查看/控制
```

## 一、主机准备（一次性）

1. 安装 PC 微信 **4.1.8.107**（不要用更新版本，wxauto 仅兼容此版本）。
   - 关闭微信「设置→通用设置→自动更新」。
   - 登录**专用工作微信号**（非客服私人号，建议实名老号、绑卡），把它拉进各工作群。
2. 拷贝 `wechat-kefu` 整个目录到主机（含 `.venv`，或在主机用 `requirements.txt` 重建）。
3. 编辑 `config.json`：
   - `general.panel_password`：改成你们自己的面板登录密码（默认 `kefu2026`）。
   - `chats`：确认要监听的群名。
   - `routing.routes`：消息转发路由（默认已按实际业务配好）。
   - `routing.shadow_mode`：保持 `true`（影子模式，先只记录不真发）。

## 二、开机自启（一次性配置）

1. 双击运行或注册计划任务（已提供脚本，管理员运行一次）：
   - `客服助手开机自启.bat` 会：开机自动拉起微信 → 启动机器人 → 崩溃退出后 5 秒自动重启。
2. 也可手动启动：双击 `启动客服助手.bat`。
3. 验证：浏览器打开 `http://127.0.0.1:43991`（本机会自动登录）。

## 三、客服日常使用

1. 客服在自己电脑浏览器打开：`http://<主机内网IP>:43991`
   - 主机 IP 可在面板「📊 运行状态」页或运行日志里看到。
2. 输入面板密码登录（登录后 7 天内免输）。
3. 常用页面：
   - **📊 运行状态**：看微信是否连接、最后消息时间、监听心跳灯。
   - **🔀 消息转发**：看每条消息被判定转发到哪个群（影子/已发状态、判定来源 llm/cache/keyword）。
   - **📝 消息记录**：按群分 Tab 查看全部消息。
   - **💬 监听会话**：勾选要监听的群。
   - 需要暂停时点「⏸ 暂停」，恢复点「▶ 恢复」。

## 四、上线步骤（影子 → 正式）

1. 影子模式运行 1~2 天，在「🔀 消息转发」核对：转发目标是否正确、有无误转/漏转。
2. 准确率确认无误后，在「🔀 消息转发」页点按钮关闭影子模式（或 config 里 `shadow_mode: false`），即开始真实转发。
3. 上线后继续观察，发现规则偏差随时可暂停。

## 五、运维要点

- **微信必须保持主窗口打开**（可最小化，别点 × 关闭）；机器人有心跳自愈，窗口意外关闭/微信重启会自动拉起重连。
- **切勿升级微信**：已做防护（禁用更新程序、锁定更新目录），若微信被更新到 4.1.13+ 会连不上，需卸载重装 4.1.8.107。
- 机器人崩溃会被守护脚本自动重启；整台主机重启后，计划任务会自动拉起。
- 数据都在 `data/`（消息库、路由日志、意图学习库），备份该目录即可。
