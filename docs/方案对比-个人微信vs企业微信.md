# 微信客服机器人：个人微信方案 vs 企业微信方案 对比

> 更新日期：2026-09-03
> 背景：客服群需要「关键词自动回复 + @对应人员 + 消息记录」。个人微信方案已开发验证完成；
> 企业微信方案基于官方文档分析，标注了需要用现成企微账号实测的待验证项。

---

## 一、结论速览

| | 个人微信方案（已验证） | 企业微信方案（待验证） |
|---|---|---|
| **账号** | ❌ 需要一个个人微信号（不能用私人号，公司暂不提供）——**当前唯一卡点** | ✅ 现成企微账号即可，机器人由企业创建、归属企业 |
| **合规性** | ⚠️ 灰色：UI 自动化模拟操作，违反微信软件许可，封号风险最低但不为零 | ✅ 官方 API，完全合规，零封号风险 |
| **触发方式** | ✅ **关键词命中即回复，不用 @**；@机器人 走 AI | ⚠️ **必须 @机器人** 才触发（官方两条路径都如此） |
| **群消息全量记录** | ✅ 全部落库 | ❌ 机器人只能收到 @它 的消息；全量记录需开通「会话内容存档」（付费+告知义务） |
| **@指定人员** | ✅ 已真机验证 | 🔶 待验证（被动回复中 @群成员 的能力） |
| **客户侧成本** | 客户在现有微信群，零迁移 | 客户需在**企业微信客户群**（微信用户可进，但群要重建/迁移） |
| **开发/部署** | 已完成：绿色 exe，一台常开电脑 | 零代码配置半天（官方自动回复）；或开发 1–2 天（智能机器人，可复用钉钉机器人代码） |
| **直接费用** | 0 | 自动回复/智能机器人：0；会话存档：约 200–900 元/人/年（第三方服务商市场价，**待核实**） |
| **稳定性** | 依赖微信界面，锁版本 4.1.8.107、关闭自动更新 | 官方接口，不受客户端版本影响 |

**一句话建议**：
- 公司若能把客服群迁到**企业微信客户群** → 企微「智能机器人」是长期最优解（合规稳定，且和现有钉钉机器人技术栈完全一致）；
- 迁移成本主要是**组织动作**（客户进新群），不是技术问题；
- 账号问题上公司既然不愿提供个人微信号，企微反而是顺理成章的方向。

## 二、个人微信方案（已验证 ✅）

**已交付**：`客服微信助手`（绿色免安装，[GitHub](https://github.com/838997125/wechat-kefu)）
技术：wxauto4 免费版 + PC 微信 4.1.8.107，UI 自动化模拟真人操作。

| 能力 | 状态 |
|---|---|
| 监听群消息、全量落库 SQLite | ✅ 真机验证 |
| 关键词自动回复（包含/全等/正则、多条连发） | ✅ 真机验证 |
| @提问人 / @指定成员 | ✅ 真机验证（已向群发送带 @ 的回复并回读确认） |
| 不 @ 也能关键词抢答 | ✅ 已实现 |
| 可选 AI 兜底（OpenAI 兼容接口+自定义提示词） | ✅ 离线自测 18/18 |
| Web 面板配置、热加载、绿色 exe | ✅ 已完成 |

**风险与限制**：
1. **账号卡点**：必须登录一个个人微信号挂机运行，不能用私人主号（封号会影响个人社交），公司暂不提供工作微信号；
2. 违反《微信软件许可及服务协议》，RPA 方案是所有个人号方案里风险最低的，但风险不为零；
3. 微信自动更新可能导致失效，已锁定 4.1.8.107 并关闭自动更新；
4. 运行时有新消息会短暂切换微信窗口（免费版机制）；
5. 需要一台常开的 Windows 电脑。

## 三、企业微信方案（待验证 🔶）

企业微信有三条官方路径，能力边界不同：

### 路径 A：客户群「自动回复」功能（零代码）

管理后台「客户联系 → 效率工具 → 自动回复」配置：
- 客户在**客户群**里 @小助理 或 @服务人员提问 → 按关键词自动回复（文字/图片/视频/网页/小程序），支持默认回复、重复回复节流；
- 每个群单独开关；
- **免费、零开发、零部署**。
- 文档：https://work.weixin.qq.com/nl/act/p/bfbc0708645f4551

局限：
- 只对**客户群**（企微成员创建、含外部微信用户）生效，内部群不适用；
- 必须 @小助理/@服务人员才触发，**不能不 @ 抢答**；
- 话术在后台配置，**不能自定义程序逻辑**（不能接我们的规则引擎/AI/业务系统）；
- 规则条数和灵活度有限（待验证上限）；
- 没有消息记录导出。

### 路径 B：智能机器人 API（推荐，可自定义）⭐

企业微信官方开放了「[智能机器人](https://developer.work.weixin.qq.com/document/path/100719)」能力，
提供**长连接**（WebSocket，无需公网服务器）和 Webhook 回调两种模式，
和我们已上线的**钉钉 ZYQ糖果机器人是同一套架构**（钉钉用的就是 Stream 长连接）：

- 用户在群里 @机器人 / 单聊机器人 → 消息加密回调推送给我们的服务；
- 支持**被动回复、主动回复、流式回复**（最长 6 分钟，适合接大模型）；
- 支持文本、图文混排、引用消息；单聊还支持图片/语音/文件；
- 官方明确支持「调用大模型/AI Agent」；
- 文档：[智能机器人长连接](https://developer.work.weixin.qq.com/document/path/101463)

**可以直接复用现有成果**：把 `dsh-plugin-dingtalk` 的 SessionBridge 模式平移成
`dsh-plugin-wecom`（长连接收消息 → 关键词规则引擎 → 回复），我们已有的规则引擎、
Web 面板、AI 兜底、消息落库逻辑大部分可直接搬用，预计 1–2 天。

局限：
- 同样**只有 @机器人 的消息才会回调**，机器人看不到群里没 @它 的聊天；
- ❌ **不能进外部客户群**（官方已确认，仅内部群可用）；适合仓库/发货/内部通知等员工群；
- 内部群回复中 @群成员能力随 API 模式可用（POC 脚本 `docs/wecom-poc/` 可验证）；
- 需要企微**管理员权限**创建机器人（现成账号是否为管理员待确认）；
- 需要一台机器跑机器人服务（长连接模式可跑在本机/内网，和钉钉机器人一样不用买云服务器）。

### 路径 C：会话内容存档（全量消息记录）

官方唯一合规获取群内**全部**聊天记录的途径：
- 文字/图片/文件/语音等全类型存档，SDK 拉取解密；
- **必须履行告知义务**（群内通知/员工协议），外部群需微信用户同意；
- 接口本身免费但需企业申请开通+自行开发；第三方服务商实施市场价约
  **200–900 元/人/年**（按开通存档的员工数，[参考](https://xiaokefu.com.cn/blog/2928.html)，**价格待核实**）；
- 注意：存档是「合规审计」能力，**不能用它的读取来驱动自动回复**（官方没有往客户群程序化发消息的配套 API），
  自动回复仍走路径 A/B。

## 四·补充：企业微信账号方案（2026-09-03 追加，**当前推荐**）

> ✅ **公司已有备用的个人企业微信账号可用**，账号和合规两个卡点都解除，推荐先走此方案。

可用账号分两种形态，能力边界相同（都归属于企业微信主体、都是管理员可控）：
- **A. 公司备用的个人企微**（现有，最快）：直接用该账号登录管理后台配置，零注册；
- B. 个人用微信/手机号免费注册企业微信（无需营业执照，注册"团队"即可）：作为没有备用账号时的备选。

官方能力与限制要点：

- ✅ 账号自有、官方合规、零封号；客户群「自动回复」(@小助理+关键词) 个人企微同样可用；
- ❌ **外部群限制与企业主体无关**：个人企微建的群只要含微信用户仍是"外部群"，智能机器人
  API 依旧进不去 → 自定义规则/接 AI/接业务系统/不@抢答，个人企微客户群同样无解；
- ⚠️ 未验证企业上限：最多 **20 个客户群**、累计 **200 个外部客户**；企业验证（管理员免费实名）后
  客户数提升到 5 万；含微信用户的群 200 人/群；
- ⚠️ **客户资产归个人主体**：公司客户沉淀在个人企微名下，离职/交接有归属纠纷风险。

适用判断：
- 只要官方合规的「@小助理关键词回复」、可接受挂个人主体 → 个人企微当天可上线；
- 要抢答/自定义规则/AI/业务系统 → 个人企微也不行，只能用已交付的个人微信 wxauto 方案
  （仍需一个工作微信号）；
- 客户要归公司 → 必须用公司企微主体。

参考：[客户群人数与企业验证上限](https://work.weixin.qq.com/nl/act/p/063b95f8c33a4275)、
[未验证企业客户群上限](https://work.weixin.qq.com/help?doc_id=12994)

## 五、待验证清单与已确认结论（2026-09-03 更新）

**第 2 项已有官方明确答案——【智能机器人不能进客户群，这是决定性限制】：**

> 企业微信帮助中心《如何使用智能机器人》原文：「内部群聊使用：仅支持添加至
> **企业内部群**，机器人可识别群内 @它 的消息并回复；**互联群、上下游群、外部群
> 暂不支持添加**。」
> 「外部群」官方定义：包含企业外部成员（企业微信用户或**微信用户**）的群聊。

含义：客服面对的是**微信客户**，客服群=外部群 → 官方智能机器人 API（长连接、@回调、
大模型、自定义程序）**在客户群用不了**，只能在纯内部员工群用。客户群唯一的官方自动
回复路径是零代码「自动回复」（@小助理关键词，不能接自定义程序/AI/业务系统）。

其余项操作步骤见《wecom-verify-guide.md》，需用现成企微账号实测：

1. 现成账号是否为**管理员**（5 分钟：能否登录 work.weixin.qq.com 后台、看到应用管理）；
2. ~~智能机器人进客户群~~ → **官方确认不行**（内部群可用，已提供长连接 POC 脚本
   `docs/wecom-poc/`）；
3. 客户群「自动回复」能否 **@指定成员**、关键词/话术条数上限（在后台配置后用微信小号实测）；
4. 客户群迁移可行性（「加入群聊」二维码引导现有微信群客户进新企微客户群）；
5. 会话存档报价（接口免费、第三方实施约 200–900 元/人/年，后台确认）；
6. 内部群智能机器人 POC（脚本已备好，填 corpid/secret 即可验证内部协同群场景）。

## 六、建议（2026-09-03 更新：公司有备用企微账号可用）

**当前推荐：以企业微信为主路线，分两层落地。**

1. **客户群（微信客户）→ 用备用企微账号开「客户群自动回复」，零开发当天可上**
   - 用备用企微登录 [work.weixin.qq.com](https://work.weixin.qq.com) → 客户联系 → 效率工具 → 自动回复，
     配高频关键词话术（查快递/营业时间/售后流程等）；
   - 建企微**客户群**，用「加入群聊」二维码引导现有微信群客户迁入（组织动作）；
   - 限制：必须 @小助理 触发、不能接自定义程序/AI、规则条数有限——满足"规则灵活但都是关键词
     自动回复"的主诉求；
   - 账号归企微主体、官方合规、零封号。未验证企业 20 群/200 客户上限，客户量大时做免费企业验证。

2. **内部协同群（仓库/发货/内部通知）→ 智能机器人 API，1–2 天可做**
   - 这类是纯员工内部群，智能机器人长连接可用，直接平移钉钉 ZYQ糖果机器人代码
     （POC 脚本已备好在 `docs/wecom-poc/`），支持 @回调、自定义规则、接 AI/业务系统。

3. **个人微信 wxauto 机器人 → 作为特殊场景兜底**
   - 只有当某个需求企微官方满足不了（如客户坚持留在普通微信群、需要不 @ 抢答、要接 DSH 工具），
     且能提供专用工作微信号时才启用；产品已全部真机验证、绿色包已发布。

4. **会话存档**：仅在管理层要求合规留痕时评估，非自动回复必要条件。

> 结论：公司提供备用企微后，「合规 + 不用个人主号 + 关键词自动回复」已完全满足，
> 优先走企微；个人微信方案降级为兜底。唯一需要接受的是客户群官方回复必须 @小助理、
> 不能接自定义 AI——这是腾讯官方限制，任何合规方案都绕不过。
