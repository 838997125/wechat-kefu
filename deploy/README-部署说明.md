# 客服微信助手 · 一键部署说明（Windows 专用主机）

本包**离线自包含**：内置 Python 安装器、全部依赖、微信 4.1.8.107 安装包、Cloudflare 公网隧道工具。
目标主机：Windows 10/11（64位），无需预装任何开发环境。

---

## 一、首次部署（约 5 分钟）

### 1. 安装微信（专用工作号，必须 4.1.8.107）
- 运行 `runtime\weixin_4.1.8.107.exe` 安装。
- 用**专用微信号**扫码登录。
- ⚠️ 不要升级微信（机器人只兼容 4.1.8.107）。登录后在 设置→关于微信 里关闭自动更新。
- 保持微信**主窗口打开**、不要点×关闭（可最小化，但不能退到完全无窗口）。

### 2. 一键安装服务
- 双击 **`1.一键安装部署.bat`**（建议右键“以管理员身份运行”，注册开机自启需要）。
- 脚本会自动：没有 Python 就静默安装内置 Python 3.12（优先使用 3.10–3.12）→ 创建独立运行环境 `.venv` → 离线装好全部依赖 → 自检 → 注册开机自启。
- 看到 `Install finished OK` 或“全部完成”即可。安装明细写入 `install-log.txt`。
- 若双击 bat 闪退/无反应：在该目录打开 cmd 手动运行 `1.一键安装部署.bat`，可看到具体报错；或直接运行 `runtime` 装好 Python 后执行 `python app\install.py`。

### 3. 启动（无黑窗，右下角托盘管理）
- 双击桌面 **「客服微信助手」** 快捷方式（或 `app\启动客服助手.vbs`）。
- 程序静默后台运行，**没有黑色控制台窗口**；屏幕右下角托盘出现一个圆点图标：
  - 🟢 绿色=运行中　🟡 黄色=已暂停　🔴 红色=微信未连接/需人工　🔵 蓝色=连接中
- 浏览器自动打开面板，或**双击托盘图标 / 右键→打开管理面板**：**http://127.0.0.1:43991**
- 本机访问面板无需密码；客服从其他电脑访问需密码（默认 `kefu2026`，**请在 `app\config.json` 里修改 `panel_password`**）。

### 4. 加入要监听的群
- 在面板「💬 监听会话」点“从微信读取会话”，勾选这几个群并保存：
  - <品牌A>客服对接群（客服源群1）
  - 聚好麦【西帕医药旗舰店-物流（客服源群2）
  - 药商通c端中通快递沟通群（中通群）
  - <物流方>&<公司简称>（催发群）
  - C端审单发货售后（仓库群）
- 当前包内 `app\config.json` 已预配好上述群和规则，一般无需改动。

## 二、日常使用

- **开机自启**：安装时已在当前用户「启动」文件夹放置静默启动项，登录 Windows 后托盘自动运行。可在托盘右键菜单里开关。
- **启停/重启**：全部在**右下角托盘图标右键菜单**完成——打开面板、暂停/恢复、重启服务、停止服务、退出。不再需要关闭黑窗口。
- **微信连不上**：机器人最多自动重试 3 次，仍失败则图标变红、停止重试（避免反复拉起微信拖垮电脑）。人工确认微信已登录后，在托盘点「重启服务」。
- **影子模式**：默认开启，只在面板记录“会把哪条消息转到哪个群”，**不真实发送**。核对几天确认准确后，在面板「🔀 多群消息转发」点按钮关闭影子模式，才会真实转发。
- **教机器人按你的判断转发（AI 自学习）**：
  - 转发日志每条右侧可点「忽略此条」（仅这一条）或「忽略并学习」（以后同类都不转，并教 AI）；
  - 「➕ 添加人工转发规则」里选源群、目标群、转发内容关键词，命中即按你的规则转发，优先级最高；
  - 这些人工标注会作为正负样本喂给大模型，逐步贴合你的判断。

### 客服远程访问（客服电脑 ping 不通主机时）
- 双击 **`启动公网访问-Cloudflare隧道.bat`**，窗口里会给一个 `https://xxxx.trycloudflare.com` 地址。
- 客服浏览器打开该地址，输面板密码即可。HTTPS 加密、不开本机端口。
- 临时隧道**重启后地址会变**，需重新发地址；要固定地址需配 Cloudflare 命名隧道（另询开发）。

## 三、包内目录

| 路径 | 内容 |
|---|---|
| `1.一键安装部署.bat` | 首次安装入口 |
| `app\启动客服助手.vbs` | 静默启动托盘（桌面快捷方式即指向它） |
| `app\tray.py` | 系统托盘程序：图标状态 + 右键启停菜单 |
| `app\` | 程序代码、配置 |
| `app\config.json` | 业务配置：监听群、转发规则、面板密码、大模型 Key |
| `app\.venv\` | 安装后生成的独立 Python 运行环境 |
| `vendor\wheels\` | 全部离线依赖安装包（含 pystray 托盘） |
| `runtime\python-3.12-amd64.exe` | Python 安装器（主机没有 Python 时自动装） |
| `runtime\weixin_4.1.8.107.exe` | 微信降级安装包 |
| `bin\cloudflared.exe` | 公网隧道工具（可选） |
| `data\` | 运行后生成：消息库、转发日志、人工规则、意图学习库（备份只需拷此目录） |

## 四、常见问题

- **托盘图标红色/提示需人工**：确认微信是 4.1.8.107、已登录、主窗口打开，然后右键托盘「重启服务」。机器人只自动重试 3 次，不会反复弹微信。
- **微信被自动升级了**：卸载后重装 `runtime\weixin_4.1.8.107.exe`，重新登录后在托盘点重启。
- **转发不准**：在转发日志点「忽略此条/忽略并学习」，或在「添加人工转发规则」里直接指定，人工反馈优先级最高；规则也可在 `config.json` 的 `routing` 段调整。
- **备份/迁移**：停掉托盘服务，拷贝整个 `app\data` 目录即可保留历史消息、转发日志、人工规则和自学习缓存。
