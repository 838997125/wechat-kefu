# 一键部署包 构建说明

最终交付给新主机的是一个**离线自包含 zip**（约 283MB），结构：

```
客服微信助手-一键部署包-vX.Y.zip
├─ 1.一键安装部署.bat          # 纯ASCII引导：找Python(无则静默装内置3.12) → 跑 app/install.py
├─ 启动公网访问-Cloudflare隧道.bat
├─ README-部署说明.md
├─ app\                        # 程序代码（与仓库根的 app/、run.py、config 等同源）
│  ├─ install.py               # 安装主逻辑：装Python/建venv/离线装依赖/自检/注册自启
│  ├─ 启动客服助手.bat
│  ├─ 客服助手开机自启.bat
│  ├─ .venv\                   # 安装后生成（不打包）
│  └─ ...（run.py、app\、config.json、requirements.txt）
├─ vendor\wheels\              # 全部离线依赖 wheel（24个，含 win_amd64 二进制）
├─ runtime\
│  ├─ python-3.12-amd64.exe    # Python 3.12 安装器（约25MB）
│  └─ weixin_4.1.8.107.exe     # 微信降级安装包（约223MB）
└─ bin\cloudflared.exe         # 公网隧道（约52MB）
```

## 大文件不进 Git
微信安装包、cloudflared、Python 安装器、wheel 二进制体积大，**不提交到代码仓库**，
通过 GitHub **Release 的资产（asset）** 分发整个 zip（Release 单文件上限 2GB）。

## 重新构建步骤（在能上外网的 Windows + Python 3.12 环境）
1. 准备空目录，按上面结构放好：
   - 代码：从仓库复制 `app/`、`run.py`、`selftest.py`、`backfill_group.py`、`requirements.txt`，
     以及一份可用的 `config.json`（含业务群名、路由、面板密码、大模型 Key）。
   - `deploy/` 下的三个 bat、`app/install.py` 放到对应位置。
2. 下载离线依赖到 `vendor/wheels`：
   ```
   python -m pip download wxauto4 flask psutil openpyxl --dest vendor\wheels --no-cache-dir
   ```
   （在 win_amd64 + Python 3.12 机器执行，确保拿到 cp312 的 pillow/pywin32/psutil 二进制）
3. 放置运行时：
   - Python: https://www.python.org/ftp/python/3.12.7/python-3.12.7-amd64.exe
   - 微信 4.1.8.107、cloudflared.exe 自备。
4. 全部 bat 必须是**纯 ASCII**（无中文/全角字符），避免目标机 cmd 用 GBK 解析 UTF-8 闪退。
5. 压缩为 zip 后，**务必在干净的中文路径下解压实测**：
   - 用非 3.12 的 python（如 3.14）跑安装脚本，验证会自动装内置 3.12；
   - 离线建 venv、装依赖、自检通过；
   - 启动 bat 能连已登录微信、面板可访问；隧道 bat 能拉起 cloudflared。
