# 客服微信助手 · 使用说明

一个运行在 Windows 电脑上的**微信群客服机器人**：自动监听指定微信群/私聊的消息，
客户消息命中关键词就自动回复（支持 @ 对应人员），可选接大模型处理规则外问题。
所有配置在浏览器管理面板里完成，**不需要懂代码**。

> 原理：模拟真人操作 PC 微信（UI 自动化），不破解、不注入、不碰微信协议。
> 请使用**专用客服微信号**，不要用个人主号。

## 📦 最快上手（绿色免安装）

1. 到 [Releases](https://github.com/838997125/wechat-kefu/releases) 下载 `客服微信助手.zip`，解压；
2. 电脑上装好 PC 微信 **4.1.8.107**、登录客服工作号、关闭微信自动更新；
3. 双击 `启动客服助手.bat`，浏览器自动打开管理面板（`http://127.0.0.1:43991`）；
4. 面板里「监听会话」勾选要值守的群，「关键词规则」里添加自动回复话术，完成。

## 一、运行环境（源码运行/开发）

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| 微信 | PC 微信 **4.1.8.107**（安装后在「设置 → 通用设置」**关闭自动更新**） |
| Python | 开发版需要 Python 3.10–3.12；**打包绿色版免安装**，客服电脑无需 Python |

## 二、启动

- **开发版**：双击 `启动客服助手.bat`（首次自动建环境装依赖）
- **绿色版**：解压打包 zip，双击 `启动客服助手.bat`

启动后浏览器自动打开管理面板（默认地址 `http://127.0.0.1:43991`，只有本机能访问）。
**关闭黑色控制台窗口即停止机器人。**

运行期间要求：
1. 微信已登录、**主窗口保持打开**（可以最小化，不要彻底关闭）；
2. 机器人有新消息时会短暂切换微信窗口读取消息，属正常现象；
3. 电脑保持开机、不断网。

## 三、管理面板说明

| 栏目 | 用途 |
|---|---|
| 📊 运行状态 | 微信连接状态、今日消息/回复数、实时日志；可手动暂停/恢复 |
| 💬 监听会话 | 点「从微信会话列表读取」勾选要自动回复的群/好友；也可手动添加 |
| ⚡ 关键词规则 | 核心功能。新增/编辑规则：关键词、匹配方式、回复内容（可多条连发）、@ 谁 |
| 🎉 新人欢迎 | 新人入群自动发欢迎语并 @ 新人 |
| 🧠 AI 设置 | 可选。规则没命中时交给大模型（支持 DeepSeek/通义/Kimi/GPT 等 OpenAI 兼容接口），可自定义客服人设提示词 |
| 📝 消息记录 | 查看全部收发消息记录和回复来源 |
| ⚙️ 系统设置 | 机器人昵称（@ 识别）、回复延时、频率上限、手动发消息测试 |

### 规则配置要点

- **关键词**：逗号分隔，命中任意一个即触发（可选“全部包含/完全等于/正则”）。
- **@ 对象**：
  - `asker` = 自动 @ 提问的客户；
  - `none` = 不 @；
  - 填**群昵称** = 固定 @ 某人（如 `仓库小王`，实现“客户催发货就 @ 仓库”）。
- **多条回复**：回复内容里一行一条，会模拟真人连发多条。
- 回复内容里 `{sender}` 会替换成提问人昵称。
- 规则按列表从上到下匹配，第一条命中即停止。

## 四、客服日常使用建议

1. 所有自动回复的群，微信号要明确是“客服助手”身份（群昵称改好，并在 `系统设置` 里填上该昵称）。
2. 先在测试群验证规则，再拉进正式客服群。
3. 规则调整在面板里保存即生效（无需重启）。
4. 机器人回复有 1–3 秒随机延时和每分钟频率上限，避免被判定异常。
5. 不要让机器人回复机器人生成的消息（系统已自动忽略本机发出的消息）。

## 五、数据与安全

- 配置：程序目录 `config.json`；消息库：`data/messages.db`；日志：`logs/bot.log`。
- 面板仅监听 `127.0.0.1`，局域网和外网无法访问。
- AI 的 API Key 只保存在本机，不上传任何第三方服务器（除你配置的大模型接口本身）。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 面板显示「微信未连接」 | 打开微信主窗口并确认已登录；微信需为 4.1.8.107 |
| 消息没反应 | 确认会话在「监听会话」里已勾选；群里关键词回复不需要 @，AI 回复默认要 @ 机器人昵称 |
| @ 不生效 | `系统设置` 的机器人昵称要与群昵称完全一致；固定 @ 某人要写群昵称 |
| 微信升级后失效 | 卸载新版、重装 4.1.8.107，并关闭自动更新 |
